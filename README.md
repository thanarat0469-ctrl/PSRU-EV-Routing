# PSRU SMART RIDE — ระบบจำลองเสมือน (Digital Twin)

## คุณสมบัติ
- หน้าจอภาษาไทย แสดงจำนวนรถ สถานะรถ และจำนวนผู้โดยสาร
- แผนที่ถนนจริงจาก OpenStreetMap ผ่าน Leaflet
- จุดสำคัญของวิทยาเขตทะเลแก้วใช้พิกัด WGS84 อ้างอิง Plus Code/ข้อมูลสถานที่ออนไลน์
- ขอเส้นทางและระยะทางตามถนนผ่าน OSRM เมื่อบริการออนไลน์พร้อมใช้งาน
- แสดงเส้นทางรถบนถนน และจำลองตำแหน่งรถเคลื่อนที่ตามแนวเส้นทาง
- เลือกจุดรับและจุดส่งจากรายการอาคาร/สถานที่จริงที่มีพิกัดอ้างอิงในวิทยาเขตทะเลแก้ว
- จุดที่เพิ่ม: หอสมุด, หอประชุมศรีวชิรโชติ, ศูนย์อาหาร ตึก ร, สนามกีฬาพระองค์ดำ, คณะเทคโนโลยีอุตสาหกรรม, คณะเทคโนโลยีการเกษตรและอาหาร และอาคารปฏิบัติการด้านอาหาร/เกษตร
- แสดงพิกัดและ Plus Code เมื่อคลิกหมุดอาคารบนแผนที่
- เพิ่มคำขอรับส่งได้จากหน้าเว็บไซต์
- AI แบบอธิบายเหตุผลได้ ประเมินรถทุกคันตามกฎและคะแนนจากโปรแกรมเดิม
- แสดงเหตุผลที่เลือกรถหรือไม่เลือกรถ และประวัติคำขอ
- ปุ่มหยุด/เริ่มการเคลื่อนที่ และรีเซ็ตข้อมูล

## วิธีติดตั้งและใช้งาน (Windows / VS Code)
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ด้วย VS Code
3. เปิด Terminal ในโฟลเดอร์โปรเจกต์
4. ติดตั้งไลบรารี: `python -m pip install -r requirements.txt`
5. เริ่มโปรแกรม: `python app.py`
6. เปิดเว็บเบราว์เซอร์ที่ `http://127.0.0.1:5000`

## ข้อควรทราบเรื่องความแม่นยำ
- แผนที่พื้นหลังและถนนมาจาก OpenStreetMap; การคำนวณเส้นทางใช้ OSRM public demo server ผ่านอินเทอร์เน็ต
- หาก OSRM ไม่ตอบสนอง ระบบจะใช้ค่าประมาณจากพิกัดแทน ไม่ควรนำไปใช้อ้างอิงการเดินรถจริง
- พิกัดจุดสำคัญเป็นจุดอ้างอิงจาก Plus Code สาธารณะ (โดยมากเป็นบริเวณอาคาร ไม่จำเป็นต้องตรงประตูรับส่ง) ควรตรวจสอบจุดจอดรับส่งกับแผนที่มหาวิทยาลัยหรือหน้างานก่อนใช้งานจริง
- ตำแหน่งรถยังเป็น Animation จำลอง ไม่ได้เชื่อมต่ออุปกรณ์ GPS บนรถ
- แผนที่ต้องใช้อินเทอร์เน็ตเพื่อโหลดแผนที่และบริการเส้นทาง
- AI เป็นระบบให้คะแนนตามกฎ (Rule-based) ไม่ใช่โมเดล Machine Learning ที่ผ่านการฝึก
